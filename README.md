# Leandro Fonseca - Portfólio

Landing page e portfólio pessoal de Leandro Fonseca, reescrito como uma aplicação moderna em React e TypeScript com Vite.

## Sobre o Desenvolvedor
- **Nome:** Leandro Santos da Fonseca
- **Formação:** Estudante do 5º semestre de Engenharia de Software na Anhanguera, formado em Educação Física
- **Atividades:** Atleta de Futebol Americano e desenvolvedor de software

## Funcionalidades
- **Apresentação & Hero:** Perfil com destaques e link direto de contato
- **Experiências:** Lista de competências em HTML, CSS, JavaScript e Node.js
- **Quem sou eu:** Biografia e trajetória acadêmica/esportiva
- **Meus Projetos:** Integração com a API do GitHub (`leosantosCODED77`) exibindo repositórios dinamicamente com tratamento de carregamento e fallback
- **Contatos & Redes Sociais:** Links diretos para Instagram, LinkedIn, GitHub e WhatsApp
- **Ações da Barra de Navegação:** Modais interativos de login e cadastro

## Tecnologias Utilizadas
- React 18
- TypeScript
- Vite
- CSS customizado com variáveis e fontes do Google (Lato & Roboto)

## Como Executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Compilar para produção
npm run build
```
